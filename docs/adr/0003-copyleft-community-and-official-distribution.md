# Copyleft community source with protected official distribution

Public source and community builds will use GPL-3.0-or-later so distributed derivatives remain open, while official store releases may use a separate project-controlled license where store terms require it. Contributors must accept a lightweight CLA that preserves attribution while granting the project rights needed for dual licensing; the project name, logo, signing keys, and other brand assets are not granted by the code license. Forks and commercial redistribution are permitted when they comply with the GPL and do not imply official status.

The intended channels are Microsoft Store, winget, signed GitHub downloads, Mac App Store, Homebrew, Flathub, and Snap, with additional native package repositories considered later. The exact CLA, trademark policy, store EULA, and compatibility of each channel require qualified legal review before public release.
