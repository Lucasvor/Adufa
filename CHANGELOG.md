# Changelog

All notable changes to Adufa are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Public beta documentation in eight languages.
- Native Windows tray popup, per-application output routing, volume controls,
  sound locator, language selection, and experimental taskbar companion.
- GitHub Actions validation, portable Windows x64 artifacts, and tag releases.

### Known limitations

- Windows is the only available beta platform.
- Taskbar companion behavior depends on Windows shell details and can fall back
  to the tray and global shortcut workflows.
- The portable beta is not code signed yet.
